# Strath Clean: Supporting Cleaning

This was the solution my team submitted to the challenge "StrathClean" at StrathHack26. For which we got 2nd place.
All built within 24hrs alongside [Elodie](https://github.com/elodiegrb), [Llywelyn](https://github.com/Llywelyn-Devoy), and [Scott](https://github.com/ScottCowe), 

# What is the app

StrathClean is meant to support cleaners and cleaning supervisors to be able to log cleans of rooms, audit other peoples cleaning, and log issues. It is meant to be a great improvement upon the current app that the cleaners use and require much less manual data entry.
